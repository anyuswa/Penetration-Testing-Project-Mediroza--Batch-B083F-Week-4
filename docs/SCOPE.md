# Scope and authorisation

The Networkwalks Week 4 brief describes an authorised educational black-box assessment of Mediroza General Hospital, planned for five days. This public copy omits the live target address and sensitive access details.

## Boundaries

- Testing is limited to the single domain specified in the original brief.
- Social engineering, denial of service and testing other systems are excluded.
- Work is independent under the brief's participant rules.
- Authorisation is stated in the project PDF; a separately signed authorisation letter is not supplied.
- This repository documents completed evidence review and provides no automated exploitation utility.

## Scope deviation visible in evidence

Two Zenmap images show a /24 subnet scan broader than the authorised domain. Other-host results are excluded from the report's findings. Disclose this deviation to the instructor and use the agreed target list for future work.

## Reporting boundaries

No new requests to the target were made during preparation of this repository. The evidence demonstrates reading/download, not host compromise, remote execution or data modification. Educational permission must not be interpreted as publication permission for confidential records.
