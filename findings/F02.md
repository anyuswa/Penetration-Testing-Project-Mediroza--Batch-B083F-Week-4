# F02 | Recoverable passwords on confidential PDFs

| Field | Value |
| --- | --- |
| Risk | High |
| Status | Open - retest pending |
| Milestone | M2 |
| Affected asset | patient_report_1.pdf, patient_report_2.pdf, patient_report_3.pdf |
| Evidence references | E28, E30; see [evidence register](../evidence/EVIDENCE_INDEX.md) |

## Observation and proof

The original artifacts use Standard PDF protection identified in ExifTool output as V2.3 (128-bit). Recovery screenshots show passwords for all three files. The copied qpdf output records decryption without errors after installation. During report preparation, each recovered password successfully decrypted its corresponding supplied PDF.

## Interpretation

The first two passwords are common dictionary/numeric choices; the third is a predictable keyboard-symbol sequence. This demonstrates weak password selection and offline recoverability, rather than a general break of 128-bit encryption.

## Demonstrated impact

All three pathology reports became readable, exposing patient identities, birth dates, identifiers, laboratory results and referring clinicians. The report summaries below retain enough information to demonstrate recovery without repeating every personal field.

## Remediation

Protect access through authenticated, authorised delivery. When file passwords are necessary, generate unique high-entropy secrets, deliver them via a separate verified channel, and use modern PDF encryption supported by recipients. Replace weakly protected exposed copies.

## Retest acceptance criteria

Confirm old copies are inaccessible, verify modern encryption settings, and review password generation for unpredictability and per-file uniqueness. Confirm patient-level authorisation remains effective even if a document URL is known.

## Publication qualification

Original screenshots and sensitive values are withheld from this public copy. The confidential reference report retains the supporting material. This record documents the authorised exercise and does not claim a new live verification.
